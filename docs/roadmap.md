  - [ ] 3.4.1 **【判明した重大な問題2】datasets キャッシュ事故**。`sft_finetune.py:246` の `dataset.map(process_instance)` は**マップ関数のフィンガープリント**でキャッシュするが、プロンプトを実際に組み立てているのは `helpers/prompting.py` の関数であり、そこだけ直しても **`process_instance` のバイトコードは変わらずキャッシュがヒットする**。結果、v2 の2実行はどちらも **7/9（修正前）のプロンプトで学習**していた（学習ログの DEBUG に `Today Date: 09 Jul 2026` と `<KEEP=none><|eot_id|><|start_header_id|>assistant...` が残存）。一方 `tokenize` は関数本体を書き換えたためフィンガープリントが変わり再実行された。よって **BOS 修正だけが効き、プロンプト構造の修正（修正1・3）は効いていなかった**。推論側はプロンプトを組み直すため、**学習と推論でプロンプト構造が食い違う**状態になった。KEEP の空出力は、モデルが「制御トークンの直後は `<|eot_id|>`」と学習したまま推論で続きを書けと指示された結果。
