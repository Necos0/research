# FKGL タグの制御はどれくらい効いているか（2026-10-29）

## 結論

- **先行研究（Taming-CATS）の Llama 1B は、FKGL タグで制御できているとは言えない。** 目標を見ずに「原文の FKGL から機械的に予想する」だけの基準より誤差が大きい。8B 級でも基準と同じ程度。
- **この研究の FKGL モデル（フル版・エポック3）は、タグで制御できている。** 目標を見ない基準や、タグを持たない NOTAG モデルより誤差がはっきり小さく、出力の FKGL が目標に連動して動いている。ただし誤差は平均 2.3 学年あり、精度は粗い。
- したがって、FKGL と KEEP の同時制御の実験で「平易化の度合いを変える」ことは、この研究のモデルなら可能。

## 1. 精度の測り方：MAE

FKGL（Flesch-Kincaid Grade Level）は、文の読みやすさを米国の学年で表した値。単語あたりの音節数と、文あたりの単語数から計算する。

制御の精度は **MAE（平均絶対誤差）** で測る。

```
MAE = 平均 |出力文の FKGL − 目標の FKGL|
```

目標は参照文（人間が平易化した文）の FKGL。MAE が 3 なら、目標から平均で 3 学年ずれている。

## 2. MAE が小さいだけでは「効いている」とは言えない

MAE は、**タグを無視しても小さくなる**。理由は2つある。

1. **目標は原文から予想できる。** 参照文は原文を少し易しくしたものなので、目標の FKGL は原文の FKGL と強く相関する（フル版 test で r = 0.77）。「原文より少し低い値」を出すだけで、目標にそこそこ近づく。
2. **目標の範囲が狭い。** 多くの目標は 8〜14 学年あたりに集まっているので、いつも平均的な難しさの文を出すだけでも誤差は一定以下に収まる。

そこで、**目標を見ずに出せる誤差（基準）** と比べる。モデルが基準より小さい誤差を出せたときにだけ、「タグの目標値を使っている」と言える。

| 基準（目標を見ない） | 内容 |
|---|---|
| 原文コピー | 原文をそのまま出す |
| 定数 | いつも同じ FKGL（目標の中央値）の文を出す |
| 原文から線形予測 | 「目標 ≈ a × 原文の FKGL + b」の最良の a, b で予想する。目標を見ない方法のなかで最も強い |

※ 定数と線形予測は「その FKGL の文を実際に作れる」と仮定した仮想的な値。線形予測は test 自身に当てはめているので、少し有利に出ている。

## 3. 先行研究：Med-EASi（フィルタ版 test 98件）

| | MAE |
|---|---|
| 基準：原文コピー | 4.25 |
| 基準：定数 | 2.94 |
| **基準：原文から線形予測** | **2.18** |
| 論文 Llama 1B（微調整あり、Table 4） | **3.96** |
| 論文 Llama 1B（微調整なし、Table 2） | 3.37 |
| 論文 Llama 8B | 2.91 |
| 論文 Mistral 7B | 2.85 |
| 論文 Qwen3 8B（最良） | 2.34 |

基準の値は、この研究の評価コードで計算した FKGL を使っている（論文の値と同じ test・同じ計算方法）。

**読み方**

- 論文の 1B（3.96）は、**目標を無視する基準のどれよりも悪い**。微調整前（3.37）より悪くなってもいる。この数値からは、1B がタグの目標値を使っている証拠は得られない。
- 最良の Qwen3 8B（2.34）でも、線形予測の基準（2.18）と同じ程度。
- 論文自身も「データに含まれる制御の信号が足りないと制御は難しい」「既存の指標はコピーを高く評価してしまう」と認めている（Discussion）。

## 4. この研究のモデル：フル版 test 203件、エポック3・3シード平均

MAE だけでなく、タグの有無で比べられる。**NOTAG** は同じデータ・同じ設定で、制御トークンを付けずに学習したモデル（目標を知らない）。KEEP も FKGL の目標は知らない。

| | MAE | 目標への係数 | 原文への係数 | 偏相関（目標 \| 原文） |
|---|---|---|---|---|
| 基準：原文コピー | 3.43 | — | — | — |
| 基準：定数 | 3.86 | — | — | — |
| 基準：原文から線形予測 | 2.89 | — | — | — |
| NOTAG（目標を知らない） | 3.18 | 0.23 | 0.74 | 0.30 |
| KEEP（FKGL の目標を知らない） | 3.35 | 0.22 | 0.77 | 0.24 |
| **FKGL** | **2.29** | **0.77** | 0.20 | **0.69** |

**列の意味**

- **係数**：出力の FKGL を「a × 原文の FKGL + b × 目標の FKGL + c」で回帰したときの a（原文）と b（目標）。目標が1学年上がると出力が b 学年上がる、と読む。
- **偏相関（目標 \| 原文）**：原文の FKGL の影響を取り除いたうえで、出力が目標とどれだけ連動するか。

**読み方**

- FKGL モデルは、目標を見ない最強の基準（2.89）より誤差が小さい（2.29）。
- 決め手は係数。NOTAG は出力が**原文に引っぱられ**（原文 0.74、目標 0.23）、FKGL は**目標に引っぱられる**（原文 0.20、目標 0.77）。タグの値で出力の難しさが動いている。
- NOTAG にも目標との連動が少しある（偏相関 0.30）のは、目標を知らなくても、文の内容から「どれくらい易しくできるか」がある程度わかるためと考えられる。FKGL との差（0.69 対 0.30）がタグの効果にあたる。
- エポック別の MAE は FKGL 2.81 → 2.39 → 2.29、NOTAG 3.58 → 3.14 → 3.18。どのエポックでも FKGL のほうが小さい。

### 同じ test 98件で論文と比べる

フィルタ版 test の98件は、すべてフル版 test 203件に含まれている。そこで、この研究のモデルの出力から98件だけを抜き出して、論文と同じ test で比べた。

| | MAE（98件） |
|---|---|
| 基準：原文から線形予測 | 2.18 |
| 基準：定数 | 2.94 |
| 論文 Llama 1B | 3.96 |
| 論文 Llama 8B | 2.91 |
| 論文 Qwen3 8B（最良） | 2.34 |
| この研究 NOTAG（エポック3・3シード） | 3.42 |
| **この研究 FKGL（エポック3・3シード）** | **2.33**（シード別 2.33 / 2.49 / 2.17） |

- 同じ test では、この研究の 1B が論文の 1B（3.96）を大きく上回り、論文の最良（Qwen3 8B、2.34）と同程度。
- ただし学習の条件が違う（学習データはフル版で事例が多い、早期終了なしで3エポック、推論回数は論文5回・この研究1回×3シード）。新しい手法で勝ったのではなく、**学習の設定の違い**による差。
- この98件では、線形予測の基準（2.18）とほぼ同じ。NOTAG（3.42）よりは明確に良いので、タグは効いているが、「目標を見ない最強の基準」をはっきり超えるほどではない。

## 5. なぜ論文の 1B と結果が違うのか（未確定）

はっきりした原因は切り分けていない。考えられる違いは次のとおり。

- **データ**：論文はフィルタ版（約1000事例）、この研究はフル版（1892事例）。フル版のほうが目標の FKGL の幅が広く（test の SD 6.2 対 3.7）、制御を学ぶ信号が多い。論文も「信号の量が制御を左右する」と述べている。
- **学習量**：論文は eval_loss による早期終了。この研究では、早期終了が1エポック未満の重みを選び、コピーが多くなることがわかっている（[roadmap ③-6](roadmap.md)）。
- **この研究の再現実験 v1**（フィルタ版、MAE 3.13）も、目標への係数は 0.29 と弱かった。ただし v1 にはプロンプト構築のバグがあった（[roadmap E1](roadmap.md)）ので、参考値にとどまる。

## 6. この研究への影響

- 同時制御（FKGL ＋ KEEP）で「目標の FKGL を下げて平易化の圧力を強めたとき、数値が落ちるか」を見る実験は、**フル版・エポック3の設定なら成り立つ**。タグで出力の難しさが実際に動くため。
- ただし誤差は平均 2.3 学年あるので、目標値どおりの難しさになるとは限らない。保持率は**目標の FKGL ごと**に加えて、**実際の出力の FKGL ごと**にも集計するとよい。
- 発表で先行研究の制御精度に触れるときは、MAE だけを出さず、**目標を見ない基準や NOTAG と並べて**示す。MAE の数字だけでは、効いているかどうかが判断できないため。

## 補足：前回の説明の訂正

最初の説明では、論文の 1B の結果と比べて「FKGL タグで制御が効いているとはほとんど言えない」と述べた。これは**論文の 1B については正しい**が、**この研究のモデル（フル版・エポック3）には当てはまらなかった**。NOTAG との比較で、タグが出力の難しさを動かしていることを確認した。
