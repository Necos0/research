`<KEEP>` タグ（提案手法）が、同一条件で学習した `<FKGL>` タグ（Taming-CATS再現）に対して
**数値保持率を改善し、平易化品質を犠牲にしていない**ことを示す比較。

- 実験ブランチ: `exp/fkgl-medeasi-1b-full` / `exp/keep-medeasi-1b`
- 結果アーカイブ: `results/fkgl-medeasi-1b-full/` / `results/keep-medeasi-1b/`（いずれも 2026-07-09 実走行）

## 実験条件の同一性（交絡の排除）

両モデルの学習設定（`models/*/args.json`）の差分は **`metric_name`（FKGL / KEEP）のみ**。

| 項目 | 共通設定 |
|---|---|
| モデル | Llama-3.2-1B-Instruct |
| 学習データ | Med-EASi フルデータ 1892事例（`data/splits_flattened_full/medeasi`、可読性フィルタなし） |
| test | 同一 203件（global_id・原文とも一致）。うち数値あり 47件 |
| 学習 | FKGL-full は epoch 1.49 で early stopping、ベスト eval_loss 1.2196 |

旧FKGL 1B（`results/fkgl-medeasi-1b/`、フィルタ済み852件学習）は学習データが異なるため**参考値扱い**とし、本表には含めない。

## 比較表

### 1. 数値保持率 — 提案手法の効果（改善の主張）

数値あり47件。保持率 = 原文中の数値のうち出力にも現れる割合（`src/helpers/keep.py: keep_retention`）。

| | FKGL-full | KEEP | reference |
|---|---|---|---|
| 平均保持率 | 0.560 | **0.674** | 0.617 |
| 完全保持（=1.0）件数 | 23/47 | **28/47** | — |

- KEEPのみが reference を上回る保持（0.674 > 0.617）。「referenceが落とした数値も保持せよ」という設計意図どおりの挙動。FKGLは逆に reference より数値を落とす（0.560 < 0.617）。
- ペア比較（ユニーク46件）: **KEEP 9勝 / FKGL 2勝 / 35分**、符号検定（両側）p≈0.065。5%有意には届かないため、発表では「傾向＋効果量（+0.11、完全保持+5件）」として提示する。

### 2. 平易化品質 — 非劣化の主張

全203件。SARI・LENSが品質の主役、BLEU_to_refは補助。

| | FKGL-full | KEEP |
|---|---|---|
| SARI | 40.66 (+2.38 −2.27) | 40.25 (+2.41 −2.31) |
| LENS | 58.98 (+2.08 −2.42) | 58.53 (+2.21 −2.42) |
| BLEU_to_ref | 22.75 | 22.74 |
| 出力の平均FKGL | 10.05 | 10.49 |

- SARI・LENSはCIが重複し同等。**保持のために品質を犠牲にしていない**。
- 出力FKGL（可読性）もほぼ同水準（参考: source 14.11、reference 11.88）。KEEPタグは平易化レベルの明示制御を捨てるが（direction.mdのトレードオフ）、出力の易しさ自体は失われていない。

### 3. 保守性チェック — 「書き換えを控えただけ」批判への検算

| | FKGL-full | KEEP |
|---|---|---|
| BLEU_to_source | 36.80 | 42.38 |
| 長さ比（出力語数/原文語数） | 0.924 | 0.946 |

- KEEPはやや原文を写す度合いが高い（保守的）。ただし §2 のとおり SARI・LENS・出力FKGL は同等であり、**保持率の改善は「書き換え放棄」の副作用ではなく、平易化を維持したまま得られている**。

### 別枠: タグ遵守度（制御MAE）

制御属性が異なるため（FKGLは学年単位、KEEPは保持率）**モデル間の直接比較はしない**。各モデル固有の遵守度として報告。

| | 値 | 対象 |
|---|---|---|
| FKGL-full の FKGL MAE | 3.33 | 203件（論文1B水準 ≈3.0–4.0 と整合） |
| KEEP の保持率 MAE | 0.319 | 数値あり47件（`numeric_sources_only: true`） |

## 注意点

- test 203件に `medeasi_000219` が重複1件（両実験共通、ユニーク202件・数値あり46件）。平均値への影響は軽微で結論は不変。
- 数値あり事例が47件と少なく、ペア比較の実効サンプルは11件（35件は引き分け）。有意性の主張には事例数の拡充が必要。
- `results/fkgl-medeasi-1b-full/logs/` には掃除ルール導入（9b33802）以前の走行のため前実験のログが混入している。本走行のログは `finetune_20260709_174125.log` / `inference_20260709_181643.log`。
